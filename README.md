# Java - Zero to First Job

Dự án này lưu trữ toàn bộ mã nguồn và bài tập thực hành trong quá trình học Java Core. 
Mục tiêu là xây dựng nền tảng Lập trình Hướng đối tượng (OOP) vững chắc và làm quen với các hệ thống quản lý mã nguồn.

## Các module chính
* Thực hành cú pháp Java cơ bản.
* Xây dựng hệ thống Siêu thị trực tuyến (Online Store).
* Thực hành quản lý phiên bản với Git & GitHub.

## Hướng dẫn chạy dự án
1. Đảm bảo máy tính đã cài đặt JDK 11 trở lên.
2. Clone dự án về máy: `git clone <đường_link_github_của_bạn>`
3. Mở thư mục dự án bằng VS Code hoặc Eclipse và biên dịch file `.java`.
