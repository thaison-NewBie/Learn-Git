# Thực Hành Java Core & OOP

Dự án này lưu trữ toàn bộ mã nguồn và bài tập thực hành trong quá trình củng cố kiến thức nền tảng Java Core và Lập trình Hướng đối tượng (OOP). Mục tiêu chính là xây dựng tư duy logic vững chắc để chuẩn bị cho các kỳ phỏng vấn thực tập vị trí Backend Developer.

## Nội dung trọng tâm
* Nắm vững cú pháp Java và cách thức quản lý bộ nhớ.
* Áp dụng thực tế các nguyên lý OOP cơ bản (Tính kế thừa, Đa hình, Đóng gói, Trừu tượng).
* Thực hành các lệnh quản lý mã nguồn cơ bản và làm việc với Git/GitHub.

## Hướng dẫn sử dụng
1. Clone dự án về máy: `git clone <đường_link_github_của_bạn>`
2. Mở dự án bằng IDE (VS Code, Eclipse...).
3. Các file mã nguồn `.java` được đặt trong thư mục `src`.
